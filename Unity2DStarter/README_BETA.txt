Tales of Ivory Moss - Beta 0.1.0
Pe Studios

This is an unsigned Windows beta build for friends and testing.
Windows SmartScreen may warn you because this build is not code-signed yet.

How to play:
- Run TalesOfIvoryMoss.exe.
- Use New Game for the beta campaign.
- Use Wrath Mode from the main menu for the combat/survival test.

Basic controls:
- A/D: move
- W or Space: jump
- S: crouch / drop through one-way platforms
- Shift: teleport dash
- Left click: selected spell or physical attack
- Right click: block/parry
- Mouse wheel: change selected power
- Esc: pause
- E: interact

Beta focus:
- Campaign flow
- Save/load
- Boss fight
- Wrath Mode combat testing

Known beta notes:
- This is not the final art, balance, or UI.
- Some animations and effects may still need manual sprite cleanup.
- Save files are stored by Unity in the game's persistent data folder.
- Do not close the game while it is saving or loading.
